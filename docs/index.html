Hushavyr

Private AI code review & security scanning

Find vulnerabilities, review code with local Ollama models, and verify proposed fixes before applying them. Free for VS Code and the terminal.

View on VS Code MarketplaceSource code on GitHubOpen VSX

Review, scan, fix and verify

  • Local AI code review with Ollama.
  • Static security analysis, secret detection and dependency vulnerability checks.
  • Review proposed changes as diffs and approve before applying them.
  • Generate failing and passing regression tests for supported workflows using an offline Docker sandbox.

See the project documentation for supported languages, prerequisites and limitations.

Privacy by default

Local-only AI routing is the default. Optional cloud escalation is disabled by default and requires explicit approval. Downloads, vulnerability database updates and Git operations may need network access. See the README for the documented behavior and setup requirements.

Get started

Install the extension from its official listing, run Hushavyr: Setup and review the proposed installation commands. Then try Hushavyr: Review Current File.

Evidence and limitations

Explore the project's reported Java OWASP benchmark and real-world benchmarks. Results are project-reported, depend on the test configuration, and do not guarantee detection of every vulnerability.
